# Тест СТМ MIKA — 30 вопросов

Интерактивный тест для продавцов-консультантов по материалам каталога СТМ (MIKA / TORRA / INALL).

## Пройти онлайн

После публикации GitHub Pages:

**https://arimberg-svg.github.io/stm-mika-quiz/**

Репозиторий: https://github.com/arimberg-svg/stm-mika-quiz

## Локально

Откройте `index.html` через локальный сервер (из‑за `fetch` к `questions.json`):

```bash
python -m http.server 8080
```

Затем откройте http://localhost:8080

## Содержание

- 30 вопросов с вариантами а/б/в/г
- Прогресс и навигация назад/вперёд
- Итог по темам + разбор ошибок
- Шкала: 24+ отлично · 18–23 хорошо · ниже 18 — повторить материал
