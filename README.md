# Презентация СТМ + тесты

Многостраничный учебный сайт для продавцов-консультантов по собственным брендам **MIKA / TORRA / INALL**.

## Онлайн

**https://arimberg-svg.github.io/stm-mika-quiz/**

Репозиторий: https://github.com/arimberg-svg/stm-mika-quiz

## Что внутри

- Стартовая презентация с логотипами брендов
- Отдельные страницы **MIKA**, **TORRA**, **INALL**
- Разделы по видам СТМ: пены, масла, насосы, растворители, стройка, инструмент, сад, автохимия
- Фото товаров и шпаргалка по пенам
- **Тест самоконтроля внизу каждой страницы**
- Большой итоговый тест на 30 вопросов (`quiz.html`)

## Локально

```bash
python -m http.server 8080
```

Откройте http://localhost:8080

## Обновление страниц

Контент HTML собирается скриптом:

```bash
python build_pages.py
```

## Структура

| Файл | Содержание |
|------|------------|
| `index.html` | Обзор СТМ и брендов |
| `brand-*.html` | Страницы брендов |
| `topic-*.html` | Виды товаров |
| `quiz.html` | Большой тест 30 вопросов |
| `assets/logos/` | Логотипы |
| `assets/products/` | Фото из каталога |
